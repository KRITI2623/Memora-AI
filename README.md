# Memora AI 🧠
Memora AI is a digital memory vault designed to help users organize and access their larning resources in one place.

## Features

-Create and manage folders
-Upload and open PDF files
-Save and open useful links
-Create and save notes
-Upload and play videos
-Upload and view images
-Search resources
-Collapsible sidebar
-Clean dashboard interface

## Technologies Used

-HTML
-CSS
-JavaScript
-Git & GitHub

## Current Status

The Frontend of Memora AI is completed and functional.

The current version handles resources using browser-side functionality. Backend integration and permanent database storage will be added in future development.

## Future Improvements

-User authentication
-Database integration
-Permanent file storage
-AI-powered search
-Semantic search
-OCR for scanned documents
-Automated resource categorization
-Cloud deployment
